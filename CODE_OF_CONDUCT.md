# Code of Conduct

with icons adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. It applies in every project space (issues, pull requests, discussions, and any chat or
event run for the project) and when someone represents the project in public.

## In short

- Be welcoming, patient and respectful. Assume good intent; critique work, not people.
- Designers, developers, first-time contributors and AI-assisted contributors are all welcome.
- Not acceptable: harassment, insults, personal or political attacks, sexualised language or imagery,
  doxxing, and any behaviour that would be inappropriate in a professional setting.

## Reporting

Report incidents privately to the maintainers through GitHub
([open a private security advisory](https://github.com/withevergrow/withicons/security/advisories/new) and mark it
"Code of conduct", or message a maintainer listed in [`.github/CODEOWNERS`](.github/CODEOWNERS)).
All reports are reviewed promptly and kept confidential.

## Enforcement

Maintainers follow the Contributor Covenant enforcement ladder: correction, warning, temporary ban, permanent ban,
depending on the severity and repetition of the behaviour.

      Are the icons really free?
      Yes. All 500 icons in all 20 styles are free for personal and commercial work under the MIT License. No sign-up, no payment, and you don't have to credit us (though we love it when you do).
      
          
      How do I put an icon in PowerPoint, Google Slides or Canva?
      Find an icon, pick a style and colour, then click Download PNG (or SVG) and insert it like any picture. In PowerPoint and Keynote, SVG stays sharp at any size and you can recolour it. Our guides walk through each app step by step.
      
          
      What's the difference between the styles?
      Every icon is drawn once and comes in twenty looks. Everyday: Line (clean outlines), Solid (bold filled) and Duo (outline with a soft tint). Crafted: Gloss (puffy and shiny), Engrave (banknote-style lines), Blueprint (technical drawing) and Sketch (hand-drawn marker). Playful: Glass (frosted glass), Kawaii (cute, with a tiny face), Sticker (die-cut Y2K sticker), Pixel (pixel art) and Retro (70s sunset stripes). Studio: Luxe (premium layered 3D), Bauhaus (primary colours and pure geometry) and Skeuo (real materials and depth). Storybook: Anime (cel-shaded anime art), Gothic (cathedral stone and stained glass), Pastel (soft candy pastels), Coquette (bows, pearls and blush pink) and Plush (soft felt toys for kids).
      
          
      Can the icons move?
      Yes, if you want them to. The optional motion add-on gives every icon a gentle loop, a hover reaction, and smooth swaps from one icon to another (play to pause, menu to close). It is imported separately, so icons stay tiny when you don't need animation, and it respects your device's reduce-motion setting. Try it above.
      
          
      Can I change the colour and size?
      Yes. Pick any colour before you download, or recolour an SVG later in your design tool. SVGs stay perfectly sharp at every size; PNGs come in sizes from 64 to 1024 pixels.
      
          
      Do I need to credit with icons?
      No credit is required. The MIT License only asks that the license text travels with the source code if you redistribute the icon files themselves as a library. Read the license in plain English.
      
          
      I'm a developer. Is there an npm package?
      Yes. Packages for React, Vue, Svelte, Angular, Solid, web components and CSS icon classes are on npm under @withicons, for example npm i @withicons/react. Prefer no install? Copy SVG code or download files from any icon page. See Developers.
      
          
      Can AI assistants use these icons?
      Yes. with icons ships an MCP server and an agent skill so coding assistants like Claude can search the library and insert the right icon, plus llms.txt for any AI that reads the web. See For AI.
